# Zetatech DeepSight
## Descripción

**Zetatech DeepSight** es una plataforma para la ingesta de datos de diagnóstico y telemetría de aplicaciones. Desarrollado por **Zeta Technologies**, está diseñado para monitorizar el funcionamiento de las aplicaciones, tratando de detectar de forma temprana, anomalías y fallos de funcionamiento.

## Proyectos

- [Api](.docs/api.md): proyecto que expone un conjunto de endpoints para la ingesta de información.
- [Application](.docs/application.md): proyecto que contiene los componentes de la capa de aplicación.
- [Domain](.docs/domain.md): proyecto que contiene los componentes de la capa de dominio.
- [Infrastructure](.docs/infrastructure.md): proyecto que contiene los componentes de la capa de infraestructura.
- [Jobs](.docs/jobs.md): proyecto que contiene los procesos que se ejecutan en segundo plano.
- [Logging](.docs/logging.md): proyecto que contiene los componentes para el registro de información de diagnóstico.
- [Telemetry](.docs/telemetry.md) proyecto que contiene los componentes para el registro de información de telemetría.
- [Triggers](.docs/telemetry.md) proyecto que contiene los desencadenadores para procesar la información ingestada.
